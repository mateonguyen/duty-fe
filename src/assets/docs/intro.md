# Giới thiệu

Duty Roster là hệ thống quản lý, lập lịch và giám sát ca trực.

## Mục tiêu chính

- Tối ưu quy trình phân công.
- Giảm lỗi thủ công.
- Cung cấp minh bạch cho toàn bộ đơn vị.

## Thành phần

- Frontend Angular 17.
- Backend .NET 8.
- Keycloak SSO.
