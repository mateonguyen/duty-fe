# Bắt đầu nhanh

Hướng dẫn nhanh để làm quen với hệ thống.

## Đăng nhập

1. Truy cập URL hệ thống.
2. Đăng nhập bằng tài khoản Keycloak.

## Xem lịch trực của bạn

Đi tới mục "Lịch trực của tôi".

## Nhận thông báo

Icon chuông hiển thị thông báo mới.
